# 回収率の研究（JRA 重賞・2023年11月〜2026年11月）

## 手順
```
python fetch_netkeiba.py --start 2022-11-12 --end 2026-11-11   # 重賞の結果・過去5走・払戻金
python fetch_horses.py                                          # 出走馬の全戦績
python research/make_predictions.py   # 各レースを「それより前のデータだけ」で予想
python research/strategy_search.py    # 研究期間で買い方を探す
python research/holdout_eval.py       # 選んだ買い方を最終テスト期間で 1 回だけ評価
```

## 進め方
- **研究期間**（2023-11-12〜2025-11-11、256 レース）だけを見て買い方を選び、
  **最終テスト期間**（2025-11-12〜2026-11-11、130 レース）は最後に 1 回だけ使う。
- 予想モデル: 市場（単勝オッズ）、全戦績ML、ベンター式（正則化 30 / 300）、2 段階ベンター式
  （戦績だけの実力 × 市場の確率を、過去レースで学習した比率で合成）。
- 単勝以外の的中確率はハービル式 + Lo & Bacon-Shone 補正で計算。
  発売中の券種別オッズはデータに無いので、単勝オッズから推定（実際の払戻と比べて 0.9〜1.04 倍の精度）。
- 判定は実際の払戻金、1 点 100 円。ブレ幅はレース単位のブートストラップ 90% 区間。

## 結果
1. **確率の正確さ（研究期間の対数損失）**: 市場 2.084 < ベンター式(300) 2.086 < 2段階 2.089 < ベンター式(30) 2.108
   < 全戦績ML(オッズあり) 2.134 < 戦績だけ 2.405。**どのモデルも市場を超えられなかった。**
2. 2 段階ベンター式の係数: 市場 ≈ 1.03〜1.14、戦績 ≈ 0.28 → 0.0（時期が新しいほど小さい）。
   - 市場の係数 > 1 は「人気馬がやや過小評価」（本命・大穴バイアス）を示す。ただし控除率(20〜27.5%)を埋めるほどの大きさではない。
3. **人気順の単純作戦は全部負け**（研究期間 30〜82%、最終テスト 67〜83%）。
4. 504 通りの「モデル × 券種 × 期待値の基準 × 点数」を研究期間で試し、前半・後半とも 95% 以上だったのは 2 つだけ:

| 作戦 | 研究期間 | 最終テスト |
|---|---|---|
| ベンター式 ワイド 期待値1.0以上 1点 | 117%（97点） | **73%**（39点） |
| ベンター式 馬単 期待値1.0以上 1点 | 123%（128点） | **95%**（55点・2的中） |
| 2段階 三連単 期待値1.1以上 5点（研究期間で最高） | 225%（71点） | 購入 0 点 |
| 人気順 複勝 1番人気 | 82% | 83% |

   近い設定（3 点・5 点買い）では研究期間でも 70〜97% に落ちており、山は偶然と判断。
   最終テスト期間でも再現しなかった。

## 結論
- 重賞では、戦績・得意条件の情報はほぼオッズに織り込まれていて、**控除率を上回る優位は見つからなかった**。
- 回収率を上げる余地があるとすれば:
  - 対象を条件戦（オッズの精度が低い）へ広げる。払戻データを増やして検証の信頼度も上げる。
  - 締切直前のオッズの動きや、パドック・馬体重など、発走直前の情報を使う。
  - 実際の券種別オッズ（馬連・三連複など）を取得して、単勝オッズとのズレを狙う。

# 複勝転がしの研究

`python research/fukusho_korogashi.py`（元手 1,000 円、払戻を全額次の複勝へ。2023年11月〜2026年11月の重賞 386 レース）

## 理屈
- 1 回の期待値を E（複勝なら約 0.8）、目標倍率を M、必要な連勝数を n とすると、成功率 ≒ Eⁿ ÷ M。
- **転がす回数が多いほど、控除率を何度も払うので成功率が下がる。** 同じ倍率の馬券を 1 回買うほうが有利（成功率 ≒ 0.8 ÷ M）。

## 結果
| ルール | 目標2倍 | 3倍 | 5倍 | 10倍 |
|---|---|---|---|---|
| 毎レース 1番人気の複勝 | 27.5% | 14.2% | 4.9% | 1.3% |
| モデル複勝率が最大の馬 | 24.9% | 11.7% | 4.1% | 0.0% |
| モデル複勝率65%以上のときだけ | 23.1% | 9.5% | 4.8% | 2.7% |
| 2番人気の複勝 | 24.7% | 12.7% | 6.2% | 1.0% |
| （参考）その倍率の馬券を 1 回だけ買う（理論） | 40% | 27% | 16% | 8% |

- 10 倍を狙う転がしの平均の戻りは元手の 0.01〜0.31 倍（1 回買いなら約 0.8 倍）。
- 複勝の回収率は単勝 1.5〜1.9 倍の馬で 90%（研究期間）/ 101%（最終テスト）と、人気薄より高い
  （本命・大穴バイアス）。ただし重賞では年に十数回しか機会がなく、100% を安定して超えるとは言えない。

## 結論
- 複勝転がしは「当たっている感覚」は得やすいが、**目標倍率の馬券を 1 回買うより確実に不利**。
- やるなら: 目標は 2〜3 倍まで、単勝 2 倍未満の強い人気馬に絞る、途中で利益を確保する。
