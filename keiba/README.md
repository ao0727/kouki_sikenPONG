# 競馬予想アプリ（Python）

出馬表 CSV を読み込み、各馬の **勝率・複勝率・期待値** と **買い目の例** を出します。
予想方式は 3 つあり、過去データで「どれが一番当たるか」を比べて選べます。

| 方式 | 中身 | 向いている場面 |
|---|---|---|
| 点数式 `score` | 過去着順・上がり・騎手・適性・枠・オッズなどに重みを掛けて合計 | データが少ないとき。`weights.json` で重みを調整できる |
| 機械学習 `ml` | 過去レースから勾配ブースティングで 1 着率・3 着内率を学習 | 過去データが数百レース以上あるとき |
| 人気順 | 単勝オッズだけ（比較用の基準） | — |

## 準備

```
pip install -r requirements.txt
```

## 使い方

```
python make_sample_data.py                       # 動作確認用のダミーデータを作る
python main.py predict data/sample_race.csv      # 予想（モデルがあれば機械学習、無ければ点数式）
python main.py train   data/sample_history.csv   # 機械学習モデル model.pkl を作る
python main.py compare data/sample_history.csv   # 方式ごとの的中率・回収率を比べる
python main.py template 出馬表.csv               # 入力用の空 CSV を作る（--with-result で着順列つき）
python main.py gui                               # 画面で操作
```

`predict` のオプション: `--method score|ml`, `--no-odds`（オッズを使わない）, `--out 結果.csv`

## 実データで検証する（netkeiba から重賞データを取得）

```
python fetch_netkeiba.py --start 2022-11-12 --end 2026-11-11 --out data/graded_history.csv
python main.py compare data/graded_history.csv --walk --test-from 2023-11-12
```

- JRA の G1〜G3（障害を除く）の結果と、各馬の「そのレース時点の過去5走」を取得します。
- `--walk --test-from` は **ウォークフォワード検証**です。指定日以降の各レースを、
  それより前のレースだけで学習したモデルで予想します（未来の情報は使いません）。
- 取得したページは `data/cache/` に保存され、2 回目以降は再取得しません。
- 個人の研究用です。netkeiba の利用規約を確認し、アクセス頻度を上げないでください。

## 馬自身の戦績・得意条件を使う（全戦績データ）

```
python fetch_horses.py --history data/graded_history.csv --out data/horse_runs.csv   # 出走馬の全戦績（約2時間）
python main.py compare data/graded_history.csv --walk --test-from 2023-11-12 --runs data/horse_runs.csv
python main.py predict 出馬表.csv --method career   # 全戦績ML（出馬表に「馬ID」列が必要）
python main.py predict 出馬表.csv --method benter   # ベンター式
```

予想するレースより前の走だけから、次の特徴量を作ります（`keiba_app/horse_features.py`）。

| 分類 | 特徴量 |
|---|---|
| 近走の調子 | 近3走の平均着差・着順率、前走着差、近5走の最高着順、着差の上向き/下向き、人気以上に走ったか |
| クラス | 前走クラス、今回とのクラス差、勝ったことのある最高クラス、重賞での複勝率 |
| 得意な条件 | 同じ距離帯・芝ダ・競馬場・回り(右/左)・馬場状態(良/道悪)での複勝率、好走した距離との差 |
| 臨戦過程 | 休養日数、休み明けか、叩き何戦目か、休み明けの成績、斤量の増減、騎手の継続、その騎手との相性 |
| 位置取り | 近5走の平均位置（前に行く馬か）、レース内の先行馬の数 |

条件別の成績は走数が少ないとブレるので、その馬の通算成績に寄せて補正しています。

| 方式 | 中身 |
|---|---|
| 戦績ML | 重賞の出走馬データ（約7,700頭分）で学習する勾配ブースティング |
| 全戦績ML | 出走馬の全キャリア（約4万走、条件戦も含む）で学習する勾配ブースティング |
| ベンター式 | オッズの確率を土台に、戦績で補正する条件付きロジット |

## 回収率の研究

単勝以外も含めた買い方の研究と結果は [research/README.md](research/README.md) にまとめています。
`predict` の出力には、券種別（複勝・ワイド・馬連・馬単・三連複・三連単）の推定期待値の上位も表示されます。

## CSV の列

1 行 = 1 頭。必須は `レースID, 馬番, 馬名`。それ以外は空欄でも動きます（入力が多いほど精度が上がる）。

```
レースID, 日付, 競馬場, 芝ダ, 距離, 馬場, 枠番, 馬番, 馬名, 年齢, 斤量, 騎手, 騎手勝率,
馬体重, 体重増減, 単勝オッズ, 前走着順, 2走前着順, 3走前着順, 前走頭数,
前走上がり3F, 前走距離, 休養週数, 距離複勝率, コース複勝率, 脚質(逃げ/先行/差し/追込)
```

過去レース CSV（`train` / `compare` 用）は、これに `着順` 列を加えたものです。
Excel で保存した Shift_JIS の CSV もそのまま読めます。

## compare の見方

- **本命の単勝的中率**: ◎ が 1 着になった割合
- **本命の複勝率**: ◎ が 3 着以内に入った割合
- **馬連(3点)**: ◎ - ○▲△ / **ワイド(2点)**: ◎ - ○, ◎ - ▲ / **3連複(10点)**: ◎ 軸 - 上位 5 頭流し
- **回収率**: 100% を超えると利益（単勝を 100 円ずつ買った場合）
- **期待値買い**: 勝率 × オッズ が 1.2 以上の馬だけ単勝を買った場合
- **対数損失**: 予想確率の正確さ。小さいほど良い。これが最小の方式を推奨として表示

日付の古いレースで学習し、新しいレースで成績を測るので、未来のデータを使った「カンニング」は起きません。

## 注意

- `data/` のサンプルは **ダミーデータ**（実在のレース・馬ではない）です。実際の的中率は実データで `compare` してください。
- `model.pkl` は自分で作ったものだけを読み込んでください（pickle 形式のため）。
