# 壁紙スライドショー (Android)

アプリ内で選んだ複数の画像を、一定間隔でホーム画面の壁紙として順番に切り替え(ループ)するアプリです。

## 機能
- 写真ピッカーから画像を好きな枚数だけ追加(何回でも追加可能)
- 長押しドラッグで表示順の並び替え、✕ で個別削除、「すべて削除」
- 切り替え間隔の選択: 15分 / 30分 / 1時間 / 2時間 / 3時間 / 6時間 / 12時間 / 1日
- ランダム順(全画像を1周するまで同じ画像は出ない)
- ロック画面にも適用するかの切り替え
- 「今すぐ次の画像へ」ボタン
- 次回の切り替え予定時刻・最後に切り替えた時刻の表示
- 端末を再起動してもスライドショーは継続(WorkManager が予約を復元)

## 仕組み
| ファイル | 役割 |
| --- | --- |
| `MainActivity.kt` | 画面(画像一覧・設定・開始/停止) |
| `ImageStore.kt` | 選択画像をアプリ内部ストレージへコピー(元画像のアクセス権が切れても動くように) |
| `SlideshowScheduler.kt` | WorkManager の定期実行の予約・停止 |
| `WallpaperWorker.kt` | 定期的に呼ばれるバックグラウンド処理 |
| `WallpaperChanger.kt` | 次の画像を選び、画面サイズにセンタークロップして壁紙に設定 |
| `SlideshowPrefs.kt` | 設定・状態の保存 |

## ビルド
Android Studio で `WallpaperSlideshow` フォルダを開いて実行してください。

- minSdk 28 (Android 9) / targetSdk 35
- 権限: `SET_WALLPAPER`(通常権限のため許可ダイアログは出ません)

## 注意
- Android の定期実行(WorkManager)は最短15分で、省電力状態(Doze)などにより数分ずれることがあります。
- 「ロック画面にも適用」をオフにしていても、ロック画面に別の壁紙を設定していない端末では、ロック画面も同じ壁紙になることがあります。
